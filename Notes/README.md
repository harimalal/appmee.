# Notes

Artefacts Claude classés ici parce qu'ils ne sont pas liés à un projet produit existant (Dropit, ArtEasy, Reflex IA...) — ce sont des notes de veille, des builds d'outils personnels ou des fiches de synthèse vidéo, rattachées à cet espace faute d'un projet plus spécifique.

- `le-systeme-maestro.html` → *Le système MAESTRO* — récit de la construction d'un skill Claude Code d'orchestration de missions autonomes (cadrage, benchmark, experts, état persistant). Projet personnel d'outillage IA, pas un produit.
- `specialisation-agents-ia-boucle-auto-amelioration.html` → *Spécialisation d'agents IA & boucle d'auto-amélioration* — fiche de veille sur une vidéo YouTube (Hugo Buisson) : spécialisation d'agents, appariement modèle/coût, mémoire structurée, boucle d'auto-amélioration.
- `hermes-agent-vps-installation-configuration.html` → *Hermes Agent sur VPS : installation & configuration* — fiche de veille sur un tutoriel d'installation de Hermes Agent en production.
- `claude-code-de-zero.html` → *Claude Code de zéro : premier site, première app, GitHub, déploiement* — fiche de veille sur un guide débutant Claude Code (Shubham Sharma).
- `blog-factory-automatisation-claude-code.html` → *Blog Factory — Automatisation Claude Code* — deck de présentation du système d'automatisation de production d'articles blog.
- `blog-factory-playbook.html` → *Blog Factory Playbook* — playbook opérationnel détaillé du même système (phases, skills, KPI, historique).

Chaque fichier est la copie de son artefact Claude publié correspondant, conservée ici pour rester retrouvable en dehors de claude.ai.
