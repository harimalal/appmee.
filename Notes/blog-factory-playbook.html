Architecture du système

Blog Factory est un pipeline de production d'articles blog qui conjugue recherche réelle, rédaction guidée et audit qualité en 4 phases autonomes. Le système génère des articles de 4000+ mots avec 16 composants obligatoires, scores >= 80/100, et maillage SEO complet.

🎯 Objectif global : Livrer un article publié directement, sans relecture manuelle, avec données vérifiées et format standardisé.

Le pipeline 4 phases en action

⏱️ Temps total : 4-6 heures pour un article complet (questions mining + recherche + rédaction + audit + publication).
Détail

Chaque phase expliquée

30-45 minutes

🔍 Phase 0️⃣ : Questions Mining

Objectif : Identifier les 10-15 vraies questions que l'audience se pose sur le sujet.

Source Qu'est-ce qu'on cherche Nombre requis
Google PAA People Also Ask — questions suggérées par Google 5+ questions
Reddit Posts authentiques avec vraies questions utilisateurs 5+ questions (avec upvotes)
Angles manqués Questions non répondues par les articles existants 3+ angles
✓ Output requis : Fichier PHASE0_questions_[date].md avec liste structurée des questions.
1-2 heures

🔗 Phase 1️⃣ : Recherche Web Réelle

Objectif : Extraire UNIQUEMENT les données vérifiées de sources authentiques (pas d'invention).

Type de recherche Sources recommandées Données à extraire Requis par outil
Pricing Site officiel + documentation pricing Free, Pro, Enterprise, add-ons, annual discount 100%
Ratings G2 + Capterra Note, nombre reviews, points récurrents 100%
Retours terrain Reddit (r/webdev, r/marketing, etc) Citations authentiques + upvotes 2+ par outil
Limitations Reddit + G2 reviews Vrais problèmes + contexte 2+ par outil
⚠️ Règle stricte : Zéro donnée inventée. Si tu trouves pas = l'article ne peut pas l'inclure.
✓ Output requis : Fichier PHASE1_recherche_[date].md avec toutes sources documentées.
2-3 heures

✍️ Phase 2️⃣ : Rédaction (16 composants obligatoires)

Objectif : Rédiger l'article en respectant la structure stricte de 16 composants.

Les 16 composants obligatoires

📊 Reading-bar
📄 Article-header
💭 Introduction
⭐ Highlight-box
📋 TOC-box
🎯 Needs-framework
🔤 H2 sections (3+)
💬 Pullquotes (2+)
🗨️ Reddit-quotes (2+)
💎 Gem-box
⛔ Redflag-box
📊 Verdict-table
❓ FAQ + JSON-LD
👣 Article-footer
🛠️ Tool-cards
💰 Pricing-blocks
Format obligatoire :
  • Fichier .md avec frontmatter charte: rich
  • Zéro CSS inline, zéro blocks <style>
  • HTML pur uniquement (composants = divs + classes)
  • Header généré par Astro (pas dans le markdown)
✓ Output requis : Fichier article_[slug].md avec 16 composants validés.
1 heure

✅ Phase 3️⃣ : Audit QA

Objectif : Vérifier la conformité, qualité, lisibilité avant publication.

Critère Standard Comment vérifier
Composants 16/16 présents et bien placés Checklist manuelle ou audit automatisé
Score article ≥ 80/100 Audit détaillé (contenu, format, données)
Maillage interne 3+ liens Reflex IA en contexte Grep ou inspection manuelle
Anti-IA patterns Zéro patterns IA détectés Scan transitions génériques + clustering adjectifs
Données sources 100% documentées et traçables Vérifier chaque donnée chiffrée
Liens externes Outils cités linkés (première mention) Vérifier vers sites officiels
✓ Go/No-go : Si tous les critères ✓, article prêt pour Phase 4 (publication).
30 minutes

🚀 Phase 4️⃣ : Publication

Objectif : Déployer l'article live sur le blog Reflex IA.

  • Copier fichier dans REFLEX IA/src/content/blog/
  • Git commit avec ID CSV + titre + date
  • Mettre à jour production_log.md (ID, titre, date, statut)
  • Mettre à jour CSV source (passer statut à « Publié »)
  • Build Astro validé (zéro erreur, 40+ pages)
  • Déploiement Cloudflare Pages (live)
✓ Article LIVE : URL accessible, indexé, prêt pour le SEO.

Lessons

Erreurs évitées et apprentissages clés

❌ Empiler les skills

Brainstorming + writing-plans + subagent = paralysie. Solution : exécution directe du processus 4 phases.

❌ Inventer des données

Phase 1 stricte = WebSearch ou rien. Pas de généralités.

❌ Multiplier les charte

4 formats (rich, visual, html-native, editorial) = bugs. Solution : charte unique « rich ».

❌ Isoler articles

Articles non maillés = faibles signaux SEO. Solution : clusters obligatoires, 3+ liens par article.

✅ Mesure par KPI

Suivi score, composants, temps, clusters. Production_log versionnée permet d'identifier tendances.

✅ Réinvention itérative

Chaque batch révèle améliorations. Feedback incorporé → articles meilleurs.
