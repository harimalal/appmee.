# Studio contenu

Un moteur commun, un pack par client.

- `moteur/carrousel/` : génération de carrousels (HTML → PNG 1080x1350 + PDF), commun à tous les clients.
- `clients/<client>/` : voix, design, thématiques, verrous, templates et carrousels du client.

Voir `.claude/skills/contenu-carrousel/SKILL.md` pour le flow.
Prérequis : Node et Playwright (Chromium).
