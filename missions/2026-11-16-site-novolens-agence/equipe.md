# ÉQUIPE — site-novolens-agence

## Directeur artistique
- Sortie attendue (livrable nommé) : L02 design-system.html et validation visuelle de L01
- Critère de succès (observable) : tous les composants du site existent dans le design system et se rendent à l'identique
- Droit de veto sur : toute page qui sort de la charte ou casse l'alternance des fonds
- Exigence portée : élégance
- Modèle conseillé : le plus puissant
- Sortie de scène : design system validé et dernière page relue
- Expert de domaine : oui

## Responsable conversion et texte
- Sortie attendue : L03 contenu.md
- Critère de succès : un objectif par page, aucun chiffre non étiqueté
- Droit de veto sur : toute phrase promettant un résultat non sourcé
- Exigence portée : fiabilité
- Modèle conseillé : le plus puissant
- Sortie de scène : contenu relu et intégré
- Expert de domaine : oui

## Motion designer
- Sortie attendue : animations des 4 étapes et du hero dans L01
- Critère de succès : chaque animation montre l'action, le moyen et le gain, et reste lisible à l'arrêt
- Droit de veto sur : toute animation qui cache du contenu ou ignore le mouvement réduit
- Exigence portée : simplicité
- Modèle conseillé : intermédiaire
- Sortie de scène : animations validées sur 3 largeurs
- Expert de domaine : oui

## Développeur front et performance
- Sortie attendue : L01 (code des 8 pages) et L04 guide.md
- Critère de succès : console sans erreur, poids respectés, accessibilité au clavier
- Droit de veto sur : tout code qui dépasse les budgets de poids ou casse l'accessibilité
- Exigence portée : fiabilité
- Modèle conseillé : intermédiaire
- Sortie de scène : audit technique passé
- Expert de domaine : non

## Vérificateur
- Sortie attendue : L05 rapport-audit.md (écarts chiffrés, liens, noms, cohérence)
- Droit de veto sur : tout livrable qui contient une affirmation non sourcée
- Exigence portée : fiabilité
- Sortie de scène : audit passé sur tous les livrables
